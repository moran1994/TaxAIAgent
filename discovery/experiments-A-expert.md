## 2. 实验组合（低成本优先）

### 实验 A — 双边假门 + 分成透明 Landing（测 V2 + B1a）

| 项 | 内容 |
|----|------|
| **测什么** | 用户是否愿为按单专家付钱；看到「专家分成 + 平台服务费」后是否仍付 |
| **做法** | 单页：AI 条款问答演示 GIF +「升级专家书面答复」；三档价 ¥99 / ¥199 / ¥399；页脚注明「咨询费按约定比例结算给接单专家」 |
| **Skin-in-the-game** | 意向金 ¥20–50（可抵扣首单）或预留微信号人工 Concierge |
| **指标** | 估价点击率；意向金转化率；档位分布；退出问卷「嫌贵 / 不信专家 / 只要免费 AI」 |
| **成功门槛** | 点击 ≥15%；意向金 ≥5；嫌贵占比 &lt;50%（否则调价/档位） |
| **失败含义** | 弱化按单或改订阅；或只做 KB |

### 实验 B — 专家供给 Concierge 招募（测 G3 + B1a + B2）

| 项 | 内容 |
|----|------|
| **测什么** | 专家是否接受「按单、收入来自用户咨询费分成」；SLA 是否扛得住 |
| **做法** | 定向邀约 10 名持证专家；合同草案：标准单到手示例（如用户付 ¥199，专家 70%≈¥139）；试运行 1–2 周，平台用人工派单（无需完整系统） |
| **Skin-in-the-game** | 专家签署试接协议 + 真实/影子答复时限承诺 |
| **指标** | 接受试接人数；平均响应时长；拒单率；对分成比满意度 |
| **成功门槛** | ≥5 人试接；SLA（如 24h）达成 ≥80%；分成「可接受」≥4/5 |
| **失败含义** | 提高专家分成 / 提高客单 / 改签约全职或合作所 |

### 实验 C — 手工 Concierge MVP（测 V2 + V3 + B1 + U2）

| 项 | 内容 |
|----|------|
| **测什么** | 真实交付路径：AI/检索草稿 → 不确定时转专家 → 用户付费 → 专家分成到账 |
| **做法** | 不建完整产品：用飞书/企微接单；运营用法规检索做「伪 AI」草稿；触发转专家后收款，再打款给专家（或当日结算表） |
| **Skin-in-the-game** | 真实付款与真实答复 |
| **指标** | 付费单数；复购/复问；单位贡献毛利（价 − 专家分成 − 支付手续费 − 人工运营分摊）；转单率与原因 |
| **成功门槛** | ≥8 笔真实付费；贡献毛利 ≥20%；无重大投诉/退款暴雷 |
| **失败含义** | 重做定价或 SLA；或证明必须先有更好 AI 降转单成本 |

### 实验 D — 窄范围条款库 Spike（测 B3 + F1）

| 项 | 内容 |
|----|------|
| **测什么** | 「增值税高频 50 题」条款图谱 + 强制引用是否可在可接受成本内达到可用质量 |
| **做法** | 2 周内容+工程 spike：建最小对象模型（Policy/Clause/时效）；混合检索；50 题黄金集评测 |
| **指标** | 人天成本；引用正确率；无依据生成率；可直接答清比例 vs 需转专家比例 |
| **成功门槛** | ≤15 人天；引用正确率 ≥70%；可答清 ≥60%（其余进专家漏斗可接受） |
| **失败含义** | A 形态过重 → 改为 FAQ/场景包轻库，专家按单仍可保留 |

### 实验 E（次优先）— 「不确定」文案可用性（测 U2）

与实验 C 同期：A/B 两句提示（「建议转专家确认」vs「以下为参考，复杂点可付费问专家」），看信任分与转单点击。成功：转单点击 ≥20% 且信任不显著下降。

## 3. 分成模型 — 实验期记账模板

每笔付费单记录：

| 字段 | 例 |
|------|-----|
| 用户实付 | ¥199 |
| 支付手续费 | ¥2 |
| 专家分成（%） | 70% → ¥139.3 |
| 平台留存 | ¥57.7 |
| 获客摊销 / 运营人工 | 另计 |
| **单笔贡献** | 平台留存 − 获客 − 运营 |

**B1 判定**：连续 8–10 单后，平均平台留存能否覆盖获客+运营并趋近 ≥20–30% 贡献毛利；同时专家 WTA 仍满足。

---

## 4. 建议执行顺序（2–4 周）

```text
Week 0–1:  实验 A（Landing）∥ 实验 B（专家招募）
Week 1–3:  实验 C（Concierge 真单 + 分成结算）← 验证收入↔专家支出挂钩
Week 1–2:  实验 D（50 题图谱 spike）∥ 并行
Week 2–3:  实验 E（文案）挂在 C 上
```

**停损规则**：A 与 B 任一在 2 周内明显失败（无点击且无专家）→ 暂停 C 的规模化，先复盘形态（改 D 专家市场优先，或去掉按单）。

## 5. 与智税宝差异（实验话术锚点）

Landing/访谈统一口径：不做一站式申报系统；做 **可追溯条款问答 + 按单真人兜底（咨询费与专家分成挂钩）**。
