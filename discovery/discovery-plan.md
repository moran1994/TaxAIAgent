# Discovery Plan — 智能税务知识库问答助手

**阶段**：新产品发现  
**决策目标**：知识库形态 + 人机协同变现  
**选定方向**：**A. 条款图谱型** + **专家按单** + **付费咨询收入与专家支出挂钩（分成）**  
**竞品锚点**：智税宝（全链路办税；我们不做申报一体，做可信问答与按单兜底）  
**中长期方向（用户补充）**：当前产品作为 **税务能力挂载底座**，后续挂接其他税务相关产品/内容（例：**企业风险咨询**），非一次性单点工具

---

## 1. 产品假设（一句话）

用户用自然语言问税务问题 → 基于可追溯条款图谱获得带引用的答案；不确定或高风险时，按单付费请真人专家书面答复；**用户咨询费按约定分成给专家与平台**；优质答复脱敏回流知识库。  
**演进**：同一账户/企业上下文上，可挂载风险咨询等内容与服务，问答与专家单成为流量与信任入口。

## 3. 选定形态（锁定供验证）

| 维度 | 选择 |
|------|------|
| 知识库 | A：法规→条款→适用条件；强制引用 RAG；时效默认现行 |
| 升级路径 | AI 低置信 / 用户主动 / 高风险标签 → 转专家 |
| 变现 | 按单咨询；**收入与专家分成挂钩**（非另薪养顾问） |
| MVP 范围建议 | 增值税等高频垂直 + 50 题黄金集，不做全税种百科 |
| 暂缓 | 场景剧本库主形态、企业私有库、全量变更流水线 |
| 平台演进 | 问答+专家为滩头；预留挂载 **企业风险咨询** 等税务产品（账号/企业档案/知识对象/交易与分成可复用） |

---

## 3.1 挂接扩展 — 对当前验证的含义

| 含义 | 建议 |
|------|------|
| MVP 仍要窄 | 先验证问答+按单分成，不把风险咨询做进首发范围 |
| 架构预留 | 企业主体、订单/履约、专家角色、知识对象、权限与分账做成可扩展，避免问答写死成烟囱 |
| 风险咨询挂接点 | 高风险问答标签 → 推荐风险咨询内容/服务包；专家单可升级为「风险评估工单」 |
| 新增待验假设（后期） | 用户是否从问答自然转化到风险咨询；风险内容偏「内容订阅」还是「项目制咨询」 |

## 4. 最关键假设（必测）

| ID | 假设 |
|----|------|
| V2 | 用户愿为单次专家书面答复付费 |
| G3 | 持证专家愿按「咨询费分成」接单 |
| B1/B1a | 存在用户 WTP ∩ 专家 WTA 的分成区间，平台扣 CAC 后仍有毛利 |
| B3 | 窄范围条款库冷启动成本可接受 |
| F1 | 强制引用质量可达发布线 |

次测：U2（不确定→转单）、B2（SLA）。

---

## 5. 验证计划（2–4 周）

| 序 | 实验 | 主要测 | 成功门槛（摘要） |
|----|------|--------|------------------|
| A | Landing 假门 + 分成说明 | V2, B1a | 估价点击 ≥15%；意向金 ≥5 |
| B | 专家招募与试接 | G3, B1a, B2 | ≥5 人试接；SLA ≥80% |
| C | Concierge 真单+分账 | V2, B1, U2 | ≥8 笔真付费；贡献毛利 ≥20% |
| D | 50 题图谱 spike | B3, F1 | ≤15 人天；引用正确率 ≥70% |
| E | 「不确定」文案（附于 C） | U2 | 转单点击 ≥20% 且信任不显著降 |

**停损**：A 与 B 两周内双杀 → 暂停放大 C；复盘是否改「专家市场优先」或去掉按单。

---

## 6. 分成记账（实验期必做）

每单：`用户实付 → 手续费 → 专家分成 → 平台留存 → 扣获客/运营 → 贡献毛利`  
目标：连续真单后平台贡献毛利趋近 **20–30%**，且专家仍愿接。

---

## 7. 决策树（实验后）

```text
V2/G3/B1 成立 + F1/B3 成立     → 继续 A+专家按单，进入 PRD / 访谈深化
V2/G3/B1 成立 + F1/B3 失败     → 保留按单分成，知识库降为轻 FAQ/场景包
V2 或 G3 失败                  → 去掉按单或改形态 D；或纯 KB 订阅
仅 G3 失败                     → 提高分成/客单，或改合作事务所供货
```

---

## 8. 推荐下一步流程

1. **访谈脚本** — 深挖财务/代账问题场景与 WTP；专家侧 WTA  
2. **写 PRD** — 在实验 A/B 启动并行也可先写 Concierge 范围 PRD  
3. **机会解决方案树** — 若要结构化展开机会再选方案  
4. **指标看板** — 为 Concierge/上线定义 NSM 与漏斗
