# 智能税务知识库问答助手 — Ideation（知识库形态）

**流程节点**：discover → ideate  
**产品阶段**：新产品  
**决策目标**：确定知识库形态 + 人机协同服务形态  
**已知证据**：竞品「智税宝」（中税网）— 一站式财税：申报算税、风险预警、法规/案例库 + AI 问答  
**新增方向（用户指定）**：**在线专家人工支持，按单结算**

## 1. Opportunity 理解

| 维度 | 假设 |
|------|------|
| 核心问题 | 财税人员查政策慢、怕漏、怕过时；通用大模型又不敢信；复杂个案必须真人背书 |
| 目标用户（初判） | 中小企业财务、代理记账；供给侧为持证税务师/顾问（专家池） |
| 我们相对智税宝 | 智税宝偏「全链路办税系统」；我们可做 **可信知识库问答 + 按单专家升级**，软件订阅与咨询单分离变现 |
| 本轮要选的 | ① 知识库形态 ② AI→专家升级时机与按单结算规则 |

## 2. 三视角发散（各 5 条，均贴「知识库形态」）

### Product Manager

| ID | 想法 | 价值点 |
|----|------|--------|
| P1 | **分层法规图谱库**：法规 → 条款 → 适用条件 → 行业/地区标签，问答必须落到条款节点 | 可审计、可对标竞品「大而全库」但结构更清晰 |
| P2 | **场景剧本库（Playbook KB）**：按「留抵退税 / 小微优惠 / 发票异常」等场景打包知识包 | 更贴近作业，而非纯法规检索 |
| P3 | **企业私有叠加库**：公共税法库 + 企业制度/历史答复/顾问笔记，双层检索 | SaaS 差异化与粘性，智税宝偏公共产品 |
| P4 | **时效版本库**：每条知识带生效/废止/过渡期，回答默认「当前有效」可切换历史时点 | 税务核心痛点：过时政策 |
| P5 | **可信度分级库**：官方原文 / 解读 / 案例 / 内部经验四级；回答展示等级与免责声明 | 建立「敢用」的信任机制 |
| P6 | **AI→专家按单升级**：低置信/高风险问题一键转专家；按单报价结算（非包月独占） | 信任闭环 + 增量变现；与智税宝「定制服务」形成可计量差异 |

### Product Designer

| ID | 想法 | 体验点 |
|----|------|--------|
| D1 | **答案卡片 = 结论 + 依据条款 + 适用边界**：先结论，展开看原文与条件 | 降低「长文淹没」 |
| D2 | **知识库浏览与问答同源**：同一图谱可浏览、可追问、可收藏条款 | 问答与学习一体 |
| D3 | **「不确定」显式态**：证据不足时要求补行业/地区/纳税人类型，不硬答 | 比假装确定更专业 |
| D4 | **对比视图**：同一问题下「现行 vs 旧规」「两地差异」并排 | 强化时效/地域形态价值 |
| D5 | **顾问工作台形态**：对话侧栏挂知识树、引用高亮、一键生成备忘录 | 面向专业用户密度 |
| D6 | **转专家工单流**：AI 草稿 + 对话上下文一并移交；报价预估 → 支付 → 回复 → 评价 | 按单体验可感知、可复购 |

### Software Engineer

| ID | 想法 | 技术形态 |
|----|------|----------|
| E1 | **混合检索 KB**：向量 + 关键词 + 结构化过滤（税种/地区/生效日） | 税务查询准确率基础 |
| E2 | **引用强制 RAG**：无检索片段不生成结论；答案绑定 chunk_id | 可追溯、可评测 |
| E3 | **法规变更流水线**：爬取/导入 → 差分 → 影响条款告警 → 人工审核入库 | 运营形态决定可信度 |
| E4 | **知识对象模型**：Policy / Clause / Condition / Case / FAQ 统一 schema | 支撑图谱与场景包 |
| E5 | **评测集即知识资产**：黄金问答集 + 引用命中率作为发布门禁 | 把质量做成可发布形态 |
| E6 | **专家单与知识回流**：工单状态机 + 支付分账；优质答复脱敏入库反哺 KB | 人机飞轮：回答越多库越强 |

## 3. 优先 Top 6（知识库形态 + 人机按单）

权重：核心价值 > 可快速验证 > 相对智税宝差异化

| 优先级 | 想法 | 合成自 | 理由 | 待测关键假设 |
|--------|------|--------|------|-------------|
| **1** | **AI→专家按单升级** | P6 + D6 + E6 | 用户明确引入；补齐「不敢信 AI」的最后一公里，且按单可独立验证付费 | 用户是否愿意为单次真人答复付费？客单价与响应时效能否匹配？ |
| **2** | **分层法规图谱 + 强制引用 RAG** | P1 + E2 + E4 | 形态底座：没有可追溯结构，问答与专家移交都不可信 | 用户是否要求「看到原文条款」才敢用？ |
| **3** | **可信度分级 + 不确定显式态 → 触发转专家** | P5 + D3 + P6 | 「不确定」不再是死胡同，而是付费升级入口 | 「不确定」是否降低信任还是提升转化？ |
| **4** | **时效版本库（现行默认）** | P4 + D4 | 税务刚需；专家答复也需绑定时效口径 | 用户是否经常查「某日有效政策」？ |
| **5** | **场景剧本库（Playbook）** | P2 + D1 | 作业包更易定价；专家可按场景包接单 | 用户是否按场景找答案，而非按法规号？ |
| **6** | **公共库 + 企业私有叠加** | P3 + E1 | 中长期壁垒；MVP 可后置 | 企业是否愿意上传内部答复/制度？ |

**暂缓**：D2 同源浏览、D5 顾问工作台（专家侧可复用部分）、E3 变更流水线、E5 评测门禁。

### 3.1 按单结算 — 形态要点（草案）

| 要点 | 建议方向（待验证） |
|------|-------------------|
| 触发 | AI 低置信 / 用户主动 / 高风险标签（稽查、筹划、金额阈值） |
| 交付物 | 书面答复 + 引用条款 +（可选）语音/图文补充；非全程陪跑顾问 |
| 计价 | 按复杂度档位（标准单 / 加急单 / 深度单），先报价后支付 |
| 分账 | **付费咨询收入与专家支出挂钩**：用户付款按分成给专家 + 平台抽成（非另薪养顾问） |
| 供给 | 兼职持证专家池；平台抽成；SLA（如 4h / 24h） |
| 飞轮 | 脱敏优质单回流知识库，降低未来同题转人工率 |
| 平台挂载（中长期） | 在问答/专家底座上挂接其他税务产品（如 **企业风险咨询** 内容与服务）；共享企业上下文、订单与分成能力 |

## 4. 产品形态候选（供决策收敛）

| 方案 | 形态一句话 | 适合验证 |
|------|------------|----------|
| **A. 条款图谱型 + 专家升级** | 条款原子库 + 强制引用；复杂题按单转专家 | 专业事务所 / 强合规 |
| **B. 场景剧本型 + 专家升级** | 场景包问答；剧本覆盖不了再转专家按单 | 中小财务 / 代账日常 |
| **C. 双层混合型 + 专家升级** | 公共 + 私有库；专家答复可沉淀进私有层 | 有内部知识沉淀的团队 |
| **D. 专家市场优先（轻 KB）** | 先做按单专家撮合，KB/AI 作辅助草稿 | 供给与付费意愿未验证时的极简路径 |

建议下一步假设测试主线：**A 或 B（知识库主形态）+ 按单专家（必测）**；D 可作为「供给先跑通」的备选实验。
