# 用户访谈脚本 — 智能税务知识库问答助手

**研究目的**：校准 OST 机会分（O1–O7）、验证付费/分成双边意愿（V2 · G3 · B1a），**不推销产品**  
**原则**：问过去行为与具体事例；不讲方案；少说多听（约 80/20）  
**形态背景（访谈中勿主动透露）**：条款可追溯问答 + 专家按单（咨询费与专家分成）  
**skill**：`interview-script`

---

## 0. 研究目标与决策

| 要回答的问题 | 对应假设/机会 | 访谈后决策 |
|--------------|---------------|------------|
| 不敢信答案的真实频率与触发点？ | O1 · V4 | 是否坚持强制引用 |
| 何时必须找真人？过去怎么找、花多少钱？ | O2 · V2 | 是否做按单专家 |
| 是否在意时效/地区/纳税人类型？ | O3 | MVP 是否做时效库 |
| 是否按「场景」找答案？ | O4 | 场景包是否后置 |
| 用户愿为一单书面答复付多少？（看过去与替代方案花费） | V2 · B1a | 定价档位 |
| 专家接零散单的条件与到手价底线？ | O5 · G3 · B1a | 分成比是否可行 |
| 风险排查类需求是否独立强烈？ | O7 | 是否另开挂载子树 |

**场次建议**：需求侧 6–8 人（财务/代账各半）；专家侧 5–8 人（持证优先）  
**时长**：需求侧 35–40 min；专家侧 30–35 min  
**招募**：最近 90 天内有过「税务拿不准」经历者；专家近 1 年有对外答复/咨询经验

## 脚本 A — 需求侧（中小企业财务 / 代理记账）

### A1. Opening（2–3 min）

> 你好，我是 [姓名]。今天想了解你在日常工作里**怎么处理税务拿不准的问题**，不是推销产品。没有标准答案，你怎么做的就怎么说。  
> 大概 35–40 分钟。方便的话我想录音，只作内部研究，不会对外具名。可以吗？  
> 时间还够吗？

### A2. Warm-Up（5 min）

1. 先介绍一下你的角色：企业财务还是代账？主要服务几家企业/什么规模？  
2. 一周里，和「税务政策、申报口径、发票」相关的事大概占多少时间？  
3. 这些问题通常是自己搞定，还是会问同事/客户/外部顾问？

### A3. Core — 最近一次「拿不准」（12–15 min）→ O1 / O3 / O4

**锚定具体事件（过去时）**

4. 请回忆**最近一次**税务上拿不准、又必须做决定的情况。大概是什么时候？什么业务背景？  
5. 当时你具体担心什么？（错报？补税？被客户追问？）  
6. 你一步步是怎么查的？用了哪些工具/渠道？（官网、群、搜索、AI、书籍、朋友……）  
7. 大概花了多长时间？中间问过谁？  
8. 最后你怎么做的决定？事后有没有被打脸或庆幸？

**痛苦与替代**

9. 那次过程里，最难/最烦的是哪一步？  
10. 你试过哪些办法改善？结果怎样？  
11. 如果答案没有「出处/原文」，你会怎么处理？

**适用边界（O3，勿诱导「时效库」）**

12. 那次有没有纠结「现在还适用吗」或「我们这个地区/这个纳税人类型适不适用」？具体怎么处理的？  
13. 有没有查过「某个历史时点当时有效的政策」的经历？最近一次是什么情况？

**场景 vs 法规号（O4）**

14. 你通常是按「业务场景」（比如留抵、优惠备案）去找答案，还是按文号/税种去找？举个最近例子。

### A4. Core — 真人求助与花费（10–12 min）→ O2 · V2 · B1a

15. 什么情况下你会觉得**必须问真人**，而不是自己查？最近一次是什么时候？  
16. 那次找的是谁？（同事、客户指定顾问、事务所、付费咨询、免费群……）  
17. 从发问到拿到可用答复，多久？对方给的是口头、微信，还是书面？  
18. **那次或类似情况，实际花了多少钱或人情？**（没有就说没有）  
19. 过去一年，这类「外部真人咨询」大概几次？累计花费量级？  
20. 有没有找过又放弃的？为什么放弃？

**Willingness / priority（仍问过去与替代，不推销）**

21. 如果当时有一个「按单、书面、带依据」的答复，你通常会拿它和什么比？（免费群、熟人或正式顾问）  
22. 你现在解决「拿不准」一年大概愿意花多少预算？（或公司/客户是否报销）  
23. 什么因素会让你**坚决不付费**？（价格、不信任、责任不清、已有顾问……）

### A5. 轻探风险咨询（3 min）→ O7（勿展开卖点）

24. 过去一年，有没有主动做过或被要求做「税务风险排查/健康检查」类的事？谁发起的？花了多少？  
25. （若有）那次和日常问答式咨询有什么不同？

### A6. Wrap-Up（3–5 min）

26. 还有什么我没问到、但对你很重要的？  
27. 还有谁也经常碰到这类问题，适合聊聊？（可请转介）  
28. 感谢你的时间。若后续有 15 分钟补充或试用类研究，方便再联系吗？（可选）

**禁止**：演示产品、问「如果有 AI+专家你会用吗」、承诺功能、争论对错。

## 脚本 B — 供给侧（税务师 / 顾问 / 事务所顾问）

### B1. Opening（2 min）

> 今天想了解你**对外答复税务问题**的真实工作方式与接单习惯，用于研究，不是招聘或签约推销。可录音，不具名。约 30–35 分钟。

### B2. Warm-Up（5 min）

1. 你的资质与主要服务对象？（企业直客 / 代账同行 / 所内派单）  
2. 一周大概答多少个「外部」问题？占比口头 vs 书面？  
3. 收入里，咨询/答疑类大概占多少？（量级即可）

### B3. Core — 最近一次对外答复（10–12 min）→ O5

4. 请讲**最近一次**你给出正式或准正式税务答复的经历（客户是谁类型即可，不必点名）。  
5. 对方一开始给了哪些材料？缺什么？你怎么补的？  
6. 你从接问到交付用了多久？中间卡在哪？  
7. 你怎么保证自己依据是现行有效的？用什么工具？  
8. 那次收费吗？怎么计价？（按时 / 按件 / 含在顾问费里 / 免费人情）  
9. 有没有「材料不齐却被催答复」的经历？你怎么处理的？

### B4. Core — 零散单与平台意向（行为优先）（10–12 min）→ G3 · B1a · B2

10. 过去一年，你有没有接过**非固定客户的零散咨询单**？怎么来的？  
11. （若有）单笔到手大概什么范围？响应时间对方期望多少？你实际做得到吗？  
12. （若无）为什么不接零散单？  
13. 什么样的单你会直接拒？（责任过大、筹划类、材料太差、价格……）  
14. 如果有人把「问题背景 + 已查到的法规摘录 + 争议点」整理好再交给你，会不会改变你接单意愿？过去有类似体验吗？  
15. **你接一单书面标准答复，到手价大概怎样才值得做？**（请给区间；可分标准/加急/深度）  
16. 结算周期上，你更能接受：单结、周结、还是月结？有过被拖欠的经历吗？  
17. 对「用户先付款、平台按比例分给你」这种模式，你过去有没有类似合作？体验如何？

### B5. 责任与回流（3–4 min）→ E1 / E3

18. 书面答复你通常如何写免责或适用范围？客户有没有误解成「官方意见」？  
19. 如果答复在脱敏后用于知识库复用，你个人能不能接受？有什么前提？

### B6. Wrap-Up（3 min）

20. 还有什么我没问到的？  
21. 所里或同行里，谁经常接这类答疑、适合聊聊？  
22. 感谢；若有试接研究（真实或影子单），是否愿意被再次联系？（可选，不施压）

**禁止**：当场谈签约分成比例定案、贬低竞品、承诺案源量。

## 探针速查（两条线通用）

| 场景 | 说法 |
|------|------|
| 浮于表面 | 「能讲得再具体一点吗？当时……」 |
| 抽象抱怨 | 「最近一次是什么时候？后来怎么样了？」 |
| 展望未来 | 「过去实际发生过吗？那次你怎么做的？」 |
| 夸奖你的想法 | 记为噪声，拉回：「你现在是怎么解决的？」 |
| 情绪波动 | 「那种感觉主要因为什么？」再追 1–2 个为什么 |

## 访谈后合成（建议）

每 3 场做一次小复盘：

1. 更新 OST Opportunity Score（Imp/Sat）  
2. 更新价带：用户替代花费分布 × 专家 WTA 区间是否重叠  
3. 标记是否触发停损（V2 或 G3 明显不成立）  
4. 金句与事例入库，供 PRD / Landing 文案（仍不在访谈中推销）

完整场次后可跑：`summarize-interview` → 再考虑 personas / journey map。
