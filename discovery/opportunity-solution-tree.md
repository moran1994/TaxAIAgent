# 机会解决方案树（OST）— 智能税务知识库问答助手

**方法**：Teresa Torres · Continuous Discovery Habits  
**输入**：`discovery-plan` · ideation · assumptions · experiments · metrics-dashboard  
**skill**：`opportunity-solution-tree`  
**更新节奏**：建议随访谈/实验每周修订

---

## 1. Desired Outcome（树顶 · 单一结果）

**提升「周可信解决次数」（Trusted Resolutions / week）**

- **定义**：AI 带有效条款引用的自助解决 + 专家按单满意交付（见 `metrics-dashboard.md`）
- **Discovery 阶段目标（草案）**：Concierge 期稳定达到 **≥8 次/周**；验证后再定 MVP 基线与月增速
- **商业约束**：专家路径上，**付费咨询收入与专家分成挂钩**，单笔贡献毛利趋近 20–30%
- **战略边界**：首发不做申报一体；中长期同一底座挂载企业风险咨询等，但不抢占本树 Outcome

> 一棵树只追一个 Outcome。风险咨询挂载另开子树/季目标。

| **O2** | 复杂/个案问题，我希望有 **真人背书**，但又不想办长期顾问 | 0.90 | 0.20 | **0.72** | 驱动专家按单 |

### 本轮优先机会（进解决方案）

1. **O2** — 按需真人背书（Score 最高带变现）  
2. **O1** — 答案可信可追溯  
3. **O3** — 适用边界与时效清晰  
4. **O5** — 专家侧愿接（双边市场成立条件）

O4 / O6 / O7 保留在树上，不进本轮主实验。

## 3. 完整树（层级）

```text
OUTCOME
└─ 提升周「可信解决」次数
   │
   ├─ O1 不敢信答案（怕幻觉/过时）
   │  ├─ S1.1 条款图谱 + 强制引用 RAG ★选定
   │  │  └─ E: 50题黄金集 spike（引用≥70%）
   │  ├─ S1.2 可信度分级 + 不确定显式态
   │  │  └─ E: 文案/原型 A/B（信任分 vs 转单）
   │  └─ S1.3 仅法规全文检索（无生成）
   │     └─ E: 任务对比（完成时间/信心）— 备选
   │
   ├─ O2 需要真人背书但不想包月顾问 ★优先
   │  ├─ S2.1 AI→专家按单升级 + 咨询费分成 ★选定
   │  │  ├─ E: Landing 假门+意向金
   │  │  └─ E: Concierge 真单分账
   │  ├─ S2.2 专家市场优先（轻 KB）
   │  │  └─ E: 纯人工撮合 2 周 — 若 S2.1 库拖垮进度
   │  └─ S2.3 订阅含 N 次专家答疑
   │     └─ E: 价档偏好调研 — 备选变现
   │
   ├─ O3 搞不清现行适用哪条
   │  ├─ S3.1 时效版本库（现行默认/可切历史）★选定配套
   │  │  └─ E: 访谈「是否查历史时点」+ 原型对比视图
   │  ├─ S3.2 强制补全槽位（行业/地区/纳税人）后作答
   │  │  └─ E: 槽位完成率可用性测
   │  └─ S3.3 两地/新旧规并排对比卡
   │     └─ E: 与 S3.1 同测
   │
   ├─ O5 专家要清楚报价、及时结算、材料齐
   │  ├─ S5.1 结构化移交工单（AI草稿+条款+争议点）★选定配套
   │  │  └─ E: 专家完备度评分（影子单）
   │  ├─ S5.2 分档报价 + 先付后答 + 自动/当日分账 ★选定
   │  │  └─ E: 专家 WTA × 用户 WTP 交叉；试接 SLA
   │  └─ S5.3 合作事务所集中供货（非散户专家）
   │     └─ E: 1 家所试点 — 若散户供给失败
   │
   ├─ O4 想按业务场景拿步骤（后置）
   │  ├─ S4.1 场景剧本库 Playbook
   │  ├─ S4.2 场景模板提问（引导式）
   │  └─ S4.3 代账作业清单插件
   │
   ├─ O6 希望企业内部口径可复用（中期）
   │  ├─ S6.1 公共库+企业私有叠加
   │  ├─ S6.2 专家答复脱敏回流
   │  └─ S6.3 企业问答空间/权限
   │
   └─ O7 想从问答接到风险咨询（后期子树）
      ├─ S7.1 高风险标签 → 风险咨询内容/服务包入口
      ├─ S7.2 专家单升级为「风险评估工单」
      └─ S7.3 独立风险 SKU（同账号企业档案）
         └─ E: 另立 Outcome 后再测 CTR/转化
```

## 4. 优先机会 × 解决方案详表

### O2 — 需要真人背书（主变现枝）

| 方案 | 视角 | 描述 | 状态 |
|------|------|------|------|
| **S2.1** | PM+Eng | AI 不确定/用户主动 → 按单专家；用户付款按分成给专家 | **本轮主方案** |
| S2.2 | PM | 先做专家撮合，KB 仅辅助草稿 | 停损备选 |
| S2.3 | PM | 订阅含次数包 | 备选定价 |

**主实验（S2.1）**

| 假设 | 方法 | 成功门槛 |
|------|------|----------|
| V2 愿付费 | Landing 假门 + 意向金 | 点击≥15%；意向金≥5 |
| G3+B1a 双边价带 | 专家试接 + WTP∩WTA | ≥5 专家；存在分成重叠 |
| B1 毛利 | Concierge 真单分账 | ≥8 真单；贡献毛利≥20% |

### O1 — 不敢信答案（主产品枝）

| 方案 | 视角 | 描述 | 状态 |
|------|------|------|------|
| **S1.1** | Eng+PM | 条款图谱 + 强制引用（无引用不硬答） | **选定形态 A** |
| **S1.2** | Design | 可信度分级；不确定显式态并导流 O2 | 与 S2.1 耦合 |
| S1.3 | Eng | 纯检索无生成 | 质量垫底备选 |

**主实验（S1.1）**：50 题图谱 spike —— 人天≤15；引用正确率≥70%；可答清≥60%。

### O3 — 适用边界不清（配套枝）

| 方案 | 状态 |
|------|------|
| **S3.1** 时效版本库 | 与 A 配套，MVP 做「现行默认」最小集 |
| S3.2 槽位补全 | 可用性跟测 |
| S3.3 对比卡 | 可后置 |

### O5 — 专家愿接（供给枝）

## 5. 本轮「比较后选定」的解决组合

> 原则：每个优先机会至少比较过 3 个方案，再锁定。

| 机会 | 选定 | 暂不选（保留） |
|------|------|----------------|
| O1 | S1.1 + S1.2 | S1.3 |
| O2 | S2.1 | S2.2 / S2.3 |
| O3 | S3.1（+轻量 S3.2） | S3.3 完整对比 |
| O5 | S5.1 + S5.2 | S5.3 |
| O4/O6/O7 | 不上本轮主路径 | Playbook / 私有库 / 风险挂载 |

**产品一句话（OST 收敛）**  
用 **条款可追溯的 AI 问答** 提高自助可信解决；用 **按单分成专家** 吃掉不敢信与复杂个案；用 **时效与槽位** 降低适用错误；用 **工单+分账** 留住供给——共同服务 Outcome「周可信解决↑」。

## 6. 实验排期（挂在树底）

与 `experiments-A-expert.md` 对齐：

| 周 | 实验 | 挂接方案 |
|----|------|----------|
| 0–1 | A Landing 假门 | S2.1 |
| 0–1 | B 专家招募试接 | S5.2 / O5 |
| 1–2 | D 图谱 spike | S1.1 |
| 1–3 | C Concierge 真单 | S2.1 + S5.1 + 分成 |
| 2–3 | E 不确定文案 | S1.2 → O2 |

**失败回路**

```text
S2.1 付费/供给失败 → 试 S2.2 或砍专家枝，Outcome 改「纯 AI 可信解决」
S1.1 引用/建库失败 → 试 S1.3 或轻 FAQ，保留 S2.1
O5 散户失败 → S5.3 事务所
O7 不进本树实验 → 风险咨询独立 OST
```

## 8. 访谈校准清单（树要「长真」）

下一轮用户/专家访谈应用来校正 Opportunity Score，而非直接问「要不要功能」：

1. 最近一次税务拿不准的场景？怕的是什么？（O1/O3）  
2. 什么情况下必须找真人？愿意为一单付多少？（O2）  
3. 是否查过「某日有效」政策？（O3）  
4. 专家：接平台单的条件与到手价底线？（O5）  
5. 是否需要风险排查类服务入口？（O7 · 仅探意向）
