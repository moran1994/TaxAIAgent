# M0-01 增值税语料清单（首发）

**状态**：草案 · 待财税专家确认效力与全文落库  
**原则**：仅收录财政部 / 税务总局等权威公开源；**禁止**未授权刮取竞品知识库  
**范围**：增值税 + 常见发票政策口径（服务问答，非申报一体）  
**更新日期**：2026-07-24

---

## Out of Scope（首发不做）

| 税种/主题 | 说明 |
|-----------|------|
| 企业所得税（完整） | 仅当与增值税进项/视同销售交叉时点到为止，不建企税专库 |
| 个人所得税 | 不做 |
| 消费税 / 关税 / 土增 / 契税等 | 不做 |
| 全行业全量发票管理办法历史沿革 | 仅留现行高频问答所需条文 |
| 地方性财政返还 / 违规筹划 | 拒答或转专家（见 M0-02） |
| 企业私有制度库 | Post-MVP |
