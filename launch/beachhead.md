## 3. 主 Beachhead 推荐

### **S1 — 代账机构「办税主办会计」**

**画像锚点**：在代账公司负责多家客户纳税申报相关答疑；微信群/同事是主信息源；需要能发给客户的「有依据说法」；包月顾问太贵，零散人情不稳定。

| 准则 | 评估 |
|------|------|
| **Burning pain** | 每日多题、怕错、客户追问；workaround（群/官网/通用 AI）脆弱 |
| **WTP** | 有小额咨询/工具支出习惯；可向客户报销或计入服务溢价；按单 ¥99–399 档需 Sprint 0 验证 |
| **Winnable** | 全国代账人多但 **可先切「某一城/某一社群联盟」** 做局部密度；不与智税宝申报一体正面硬刚，打「可信问答+按单」 |
| **Referral** | 代账群口碑强；一人试用多人问；可扩到其客户企业财务（S2） |

**为何不是 S2 先发**：企业财务更散、CAC 高、转荐弱；适合 beachhead 站稳后的相邻扩张。

## 4. 滩头「荒谬地具体」切口（90 天内）

> **目标城或社群内的增值税日常合规问答（抵扣、发票、小微优惠）代账主办**，先吃透，不做全税种、不做全国撒网。

**局部市场份额叙事（务实版）**：不追求「全国代账 60%」，而追求 **选定社群/城市圈内「用过按单专家问答的代账主办」心智第一**（可测：社群提及率、复购、转荐数）。

## 5. 定价与动作含义（假门）

| 项 | Beachhead 含义 |
|----|----------------|
| Landing 话术 | 「代账每天要答的税问，有出处；搞不定按单找专家」 |
| 渠道 | 代账培训群、本地代账协会/社群、KOC 主办会计，**定向 50–100 人** |
| 勿讲 | 一站式申报、集团风控、全税种百科 |
| 专家供给 | 优先能写「代账客户常见增值税书面答复」的持证兼职 |
| 相邻扩张 | S1 → 其客户企业财务（S2）→ 风险咨询挂载（后期） |

## 6. 90 天获客草案（服务 Beachhead）

| 阶段 | 动作 | 成功信号 |
|------|------|----------|
| D0–14（S0） | 定向邀约假门；访谈代账主办 ≥5；专家试接 | 点击/意向金/价带 |
| D15–45 | 邀测 Concierge；社群案例（脱敏） | ≥8 真单；转荐 ≥3 |
| D45–90 | 固化 1–2 个社群渠道；复制到第二社群 | 周可信解决稳定；CAC 可粗算 |
