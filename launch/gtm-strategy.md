# GTM 策略 — 智能税务知识库问答助手（Sprint 0 假门）

**Beachhead**：S1 代账主办 × 增值税日常  
**阶段**：验证上市（Landing 假门 + 定向邀约），非大公测  
**skill**：`gtm-strategy`

---

## 1. 战略一句话

> 在选定代账社群内，用「条款可追溯问答 + 按单专家（咨询费分成）」占据心智；用假门与 Concierge 验证愿付与转荐，再小流量扩。

**不打**：全国品牌广告、与智税宝比拼申报一体。

---

## 2. 定位与信息

| 层 | 文案 |
|----|------|
| **Category** | 可信税务问答（非申报系统） |
| **For** | 代账办税主办 |
| **Promise** | 日常税问有出处；搞不定按单找持证专家书面答 |
| **Unlike** | 通用 AI（无依据）/ 一站式办税软件（重、贵、慢） |
| **Proof（S0）** | 答案示例截图、分成透明说明、专家资质、意向用户数 |

### 主信息支柱

1. **敢用**：结论绑定条款原文与时效  
2. **敢升级**：不确定不硬撑，按单真人兜底  
3. **算得清**：先报价后付；咨询费与专家结算挂钩  

### 禁止信息

- 「保证少交税 / 筹划保过」  
- 「替代税局 / 官方意见」  
- 「全税种百科已覆盖」

## 3. 渠道（少而精）

| 优先级 | 渠道 | 用途 | S0 动作 |
|--------|------|------|---------|
| P0 | **代账社群 / 培训群** | 定向邀约假门 | 找 1–2 个群主/KOC，发专属链接 |
| P0 | **1:1 私域邀约** | 访谈+试用 | 名单 50 人，企微/微信触达 |
| P1 | 财税内容短帖（朋友圈/社群） | 信任预热 | 3 条「有出处 vs 幻觉」对比帖 |
| P2 | 搜索 SEO | 中期 | S0 不做投放规模化 |
| 暂缓 | 泛量信息流广告、ABM 大客户 | CAC 过高/错配 | — |

## 4. 成功指标（对齐假门）

| 漏斗 | 指标 | S0 门槛 |
|------|------|---------|
| 触达 | 定向触达人数 | ≥50 代账主办 |
| 兴趣 | Landing UV（定向） | 不追求大盘，看名单打开率 |
| 意愿 | 估价点击率 | ≥15% |
| Skin | 意向金或预约数 | ≥5 |
| 供给 | 专家试接确认 | ≥5 |
| 学到 | 访谈完成 | 需求≥5 / 专家≥5 |
| 转荐（领先） | 主动介绍同行 | ≥1（加分） |

业务 NSM 仍以「可信解决」为准，S0 以验证指标为主。

## 5. 分期时间表

### Pre-launch（S0 Week 1）

- 定稿 Landing 文案（三支柱 + 三档价 + 分成一句）  
- 冻结邀约名单与社群入口  
- 专家协议一页纸 + 入驻表  
- 10 题图谱小样启动  

### 「Launch」日（假门上线日）

- 社群+私域同步发专属链接  
- PM 在线答疑（非销售逼单）  
- 仪表：点击/意向金实时表  

### Post（S0 Week 2）

- 催未点估价用户补访谈  
- Concierge 真单尝试  
- Go/No-Go 会（对齐 sprint-plan 闸门）  

### 若 Go → 45–90 天

- 邀测扩第二社群；沉淀 1 个脱敏案例；粗算 CAC

## 6. 风险与缓解

| 风险 | 缓解 |
|------|------|
| 社群厌恶广告 | KOC 转发「研究邀请」话术，限名额 |
| 被当成又一个 AI | 首屏放引用答案卡，而非机器人头像 |
| 专家供给空 | 假门与专家招募并行，供给未齐不承诺 4h SLA |
| 合规话术越界 | 法务过免责与「非官方」一句 |

---

## 7. 资源（最小）

- PM：名单、文案、访谈、Go/No-Go  
- Design：单页 Landing + 答案卡示意  
- 运营：专家入驻、真单 SOP  
- Eng：假门统计 +（可选）极简表单  
- 预算：社群合作小额 / 意向金通道手续费；**不做大额广告**
