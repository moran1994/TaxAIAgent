## 1. Summary

本 PRD 定义一款面向中小企业财务与代理记账的 **可信税务问答产品**：用「条款图谱 + 强制引用」回答日常问题；复杂或低置信问题时，用户可 **按单付费** 获得在线专家书面答复，**咨询费与专家分成挂钩**。首发不做申报/风控一体系统；架构预留后续挂接企业风险咨询等税务产品。

## 3. Background

### 3.1 Context

财税人员日常大量时间花在「查政策、对口径」。通用大模型答得快但 **不敢用**；官网与文库难检索；熟人顾问贵且响应慢。竞品如智税宝偏 **一站式办税与大库**，我们选择滩头：**可信问答 + 按需真人兜底**，用可追溯知识库形态建立差异，并用按单咨询切入付费。

### 3.2 Why now

- 生成式 AI 使「自然语言问税务」成为习惯，但幻觉与过时政策风险同步放大，**强制引用与人工升级**成为刚需。  
- 兼职专家与在线分账基础设施成熟，适合验证「咨询费 → 专家分成」双边模型，而不必先养全职顾问团队。  
- Discovery 已选定形态 **A（条款图谱）+ 专家按单**，并明确中长期做 **可挂载税务产品底座**（如企业风险咨询）。

### 3.3 What recently became possible

混合检索 + RAG 评测门禁、按单支付与分账、低成本 Concierge 验证，使团队可在建完整申报系统之前验证价值与单位经济。

## 4. Objective

### 4.1 Goal

让目标用户在增值税等高频场景下，**更快、更敢用地解决税务拿不准问题**；在必须真人时，用可预期价格与时限拿到书面答复；平台在分成后仍可持续运营，并为后续挂载产品积累企业与信任资产。

### 4.2 Benefits

| 对象 | 收益 |
|------|------|
| 客户（财务/代账） | 自助答案可追溯；复杂题按单找专家，不必包月 |
| 专家 | 结构化来单、先付后答、按分成结算 |
| 公司 | 验证 NSM 与毛利；沉淀条款库与交易能力，支撑挂载 SKU |

### 4.3 Alignment

- **战略**：不做智税宝式全链路；占「可信问答 + 人机协同」滩头。  
- **平台**：账号、企业主体、订单、专家、知识对象、分账可复用到风险咨询等。

### 4.4 Key Results（SMART · 草案）

| KR | 目标 | 时间窗 |
|----|------|--------|
| KR1 | 周「可信解决」≥ 8（Concierge）并建立基线 | 验证期 2–4 周内达成并稳定 2 周 |
| KR2 | AI 引用合格率 ≥ 70%（黄金集/抽检） | MVP 发布门禁 |
| KR3 | 专家单 SLA（如 24h 档）达成率 ≥ 90% | MVP 发布后持续 |
| KR4 | 付费专家单贡献毛利 ≥ 20%（目标 20–30%） | 连续 ≥10 笔真单后评估 |
| KR5 | 无引用硬答率 ≤ 5%；付费退款/争议率 ≤ 5% | 护栏，持续 |

北极星定义见 `discovery/metrics-dashboard.md`。

## 5. Market Segment(s)

市场按 **要完成的工作（Job）** 定义，而非年龄地域。

### 5.1 主细分（需求侧）

| 细分 | Job | 约束 |
|------|------|------|
| **Seg-A 中小企业财务** | 在申报/发票/优惠场景快速得到「可交代给老板或税局口径」的答案 | 预算有限；怕担责；时间碎 |
| **Seg-B 代理记账会计** | 同时服务多家客户，快速定位适用政策并留下可追溯依据 | 题重复率高；客单价敏感；需可复制话术 |

### 5.2 供给细分

| 细分 | Job | 约束 |
|------|------|------|
| **Seg-E 持证兼职专家** | 用碎片时间接标准化书面单并获得及时分成 | 要材料齐、责任边界清、到手价够 |

### 5.3 非目标（MVP）

- 大型集团税务共享中心（流程与权限过重）  
- 以申报填表/发票勾选为主需求的用户（导向竞品）  
- 激进税务筹划「保证节税」类诉求（伦理与合规排除）

## 6. Value Proposition(s)

### 6.1 Jobs / Pains / Gains

| | 内容 |
|--|------|
| **Jobs** | 查清现行适用政策；留下可追溯依据；复杂题获得真人书面意见 |
| **Pains 规避** | 幻觉与过时政策；包月顾问过贵；免费群不可靠；查文号耗时长 |
| **Gains** | 结论+条款+适用边界；不确定时可升级；按单付费可预期 |

### 6.2 相对竞品（智税宝等）

| 维度 | 我们 | 典型一站式竞品 |
|------|------|----------------|
| 重心 | 可信问答 + 按单专家 | 申报/风控/管理一体 |
| 知识形态 | 条款图谱强制引用 | 大库 + AI，引用深度不一 |
| 变现 | 咨询费与专家分成 | 软件/服务打包 |
| 扩展 | 挂载风险咨询等 SKU | 功能模块扩张 |

### 6.3 Value Curve（简）

刻意做高：**可追溯性、按需真人、单位经济透明**。  
刻意不做高（MVP）：**申报自动化、全税种覆盖、深度筹划**。

## 7. Solution

### 7.1 UX / 主流程

```text
[登录/游客限制策略 TBD]
    → 提问（可补：税种/地区/纳税人类型）
    → AI 检索条款图谱
    → 答案卡：结论 | 依据条款 | 适用边界 | 时效
         ├─ 高置信：结束 / 追问 / 收藏
         └─ 低置信或用户点击「转专家」
              → 展示估价档位与分成说明（透明）
              → 支付
              → 生成结构化工单（问题+上下文+已检索条款+争议点）
              → 专家接单 → 书面交付 → 评价
              → 分账（专家分成 + 平台留存）
              → （可选）脱敏回流知识库
```

**答案卡原则**：先结论，再依据；无检索命中不得生成确定性结论（强制引用）。  
**不确定态**：明确说明缺口，引导补槽位或转专家——转专家是增值路径，不是甩锅。

**线框优先级（Design）**

1. 对话 + 答案卡 + 引用展开  
2. 转专家估价 / 支付 / 进度  
3. 专家工作台（待接、材料、交付、SLA 倒计时）  
4. 运营：分账流水、黄金集评测（可后置后台）

### 7.2 Key Features

#### P0 — Concierge / MVP 必须

| ID | 功能 | 说明 | 验收要点 |
|----|------|------|----------|
| F1 | 条款图谱问答 | 对象：Policy / Clause / Condition / 时效；混合检索 | 无 chunk 不输出确定结论 |
| F2 | 引用展示 | 条款标题、文号、生效区间、原文片段 | 用户可点开原文级依据 |
| F3 | 槽位追问 | 行业/地区/纳税人类型等影响适用时必问 | 缺槽位则标不确定 |
| F4 | 转专家 CTA | 低置信、高风险标签、用户主动三入口 | 曝光与点击可埋点 |
| F5 | 按单报价与支付 | 标准/加急/深度等档位；先付后答 | 价档可配置 |
| F6 | 咨询费分账 | 用户实付 → 手续费 → 专家分成 → 平台留存 | 与约定分成比偏差可稽核 |
| F7 | 专家工单 | 状态机：待支付/待派/进行中/已交付/退款/关闭 | SLA 计时 |
| F8 | 结构化移交 | AI 草稿+对话+命中条款打包给专家 | 专家侧完备度可评分 |
| F9 | 免责与资质 | 用户侧「仅供参考」；专家资质展示 | 法务审过模板 |
| F10 | 黄金集门禁 | 发布前跑引用正确率 | ≥70% 才扩量 |

#### P1 — MVP 增强

| ID | 功能 | 说明 |
|----|------|------|
| F11 | 时效「现行默认」 | 回答绑定当前有效；历史时点查询可简版 |
| F12 | 可信度分级 | 官方原文 / 解读 / 案例 标识 |
| F13 | 评价与退款流 | 差评触发复核；退款规则透明 |
| F14 | 问题聚类与回流 | 高频题优先入库 |
| F15 | 企业主体占位 | `org` 实体，为挂载预留，MVP 可仅账号级 |

#### P2 — 后续版本

| ID | 功能 | 说明 |
|----|------|------|
| F16 | 场景剧本库 Playbook | O4 后置 |
| F17 | 企业私有知识叠加 | O6 |
| F18 | 企业风险咨询挂载 | O7：入口、独立 SKU、可升级自专家单 |
| F19 | 全量法规变更流水线 | 自动化差分与审核 |
| F20 | 订阅含 N 次专家 | 备选包装，非默认 |

### 7.3 Technology（要点）

| 层 | 建议 |
|----|------|
| 检索 | 向量 + 关键词 + 结构化过滤（税种/地区/生效日） |
| 生成 | 仅基于命中片段组织答案；拒绝无依据结论 |
| 评测 | 离线黄金集 CI + 在线抽检 |
| 交易 | 第三方支付；分账或日结打款表（Concierge 可先人工） |
| 数据 | 事件埋点对齐指标看板；`orgs`/`tickets`/`payouts`/`kb_nodes` 可扩展 |
| Concierge | 允许飞书/企微 + 人工派单验证 F5–F8，再产品化 |

### 7.4 Assumptions（未证伪前当风险）

| ID | 假设 | 验证 |
|----|------|------|
| V2 | 用户愿为单次专家书面答复付费 | Landing / Concierge |
| G3 | 专家接受咨询费分成接单 | 试接 |
| B1/B1a | 存在 WTP∩WTA 且平台有毛利 | 真单分账 |
| B3/F1 | 窄范围图谱成本与引用质量可达线 | 50 题 spike |
| U2 | 「不确定」促进转单而非流失 | 文案实验 |
| B2 | SLA 可维持 | 试运行 |

## 8. Release

避免死日期，用相对阶段。

### Phase 0 — Discovery Concierge（约 2–4 周）

- Landing 假门、专家招募、人工真单分账、50 题图谱 spike  
- **出口**：V2/G3/B1 与 F1/B3 过门或触发停损改范围  

### Phase 1 — MVP（约 6–10 周，自 Phase 0 通过起）

**In**

- F1–F10 核心闭环；增值税等高频垂直  
- 专家池小规模运营；基础埋点与分账报表  
- 企业主体仅占位字段  

**Out**

- 全税种百科、申报一体、风险咨询完整 SKU、私有库、Playbook 主形态  

### Phase 2 — 硬化与扩展（MVP 后）

- F11–F15；回流飞轮；供给扩容；毛利与 SLA 稳定  

### Phase 3 — 平台挂载

- F18 企业风险咨询等内容/服务；共享账号、企业档案、订单与分成  
- 另立 Outcome / 子 PRD，不膨胀本 PRD 范围  

### 依赖与风险

| 风险 | 缓解 |
|------|------|
| 建库人力爆炸 | 锁垂直 + 黄金集；不达标则降为轻 FAQ |
| 供给不足 | 提高分成/客单；或改事务所供货 |
| 合规与误用 | 强免责、禁筹划承诺、资质审核 |
| 分账差错 | P0 对账；Concierge 先简后繁 |
