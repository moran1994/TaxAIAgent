# PRD — 智能税务知识库问答助手（MVP）

**产品名（暂定）**：条款问税（可改）  
**版本**：MVP / Concierge  
**状态**：可开工（Discovery 已锁定形态；商业假设边做边验）  
**依据**：`discovery/discovery-plan.md` · 竞品锚点智税宝（我们不做申报一体）  
**日期**：2026-07-24

---

## 1. Summary

做一款**增值税等高频场景**的税务问答助手：答案必须带**可点击的法规条款引用**；AI 不确定或用户主动升级时，可**按单付费转持证专家书面答复**，咨询费与专家**分成**。MVP 验证「敢用 + 愿付 + 专家愿接」，并为后续挂载企业风险咨询预留账号/工单/分账能力，**不做**全税种百科、发票购销链、申报算税。

## 3. Background

- 通用大模型查税「像那么回事」但**不敢当作业依据**；查原文又慢。  
- 智税宝等偏**全链路办税/大库**；中小财务与代账更缺的是：**带依据的快答 + 必要时真人兜底**。  
- Discovery 已选定：**A 条款图谱 + 强制引用 RAG + 专家按单分成**；中长期作税务能力挂载底座（如企业风险咨询）。  
- **Why MVP now**：形态已锁；用 Concierge MVP 同时交付可用产品和测 V2/G3/B1/F1，避免先空转实验再开工的断层。

---

## 4. Objective

**目标**：4–8 周内上线可用的窄域问答 + 专家按单闭环，证明用户愿付、专家愿接、引用质量过线。

**Key Results（MVP 窗口）**

| KR | 指标 | 目标 |
|----|------|------|
| KR1 | 黄金集引用正确率（增值税 50 题） | ≥70%；无依据胡答 ≤5% |
| KR2 | 真付费专家单 | ≥8 笔 |
| KR3 | 专家试接 SLA（约定 24h 内书面回） | ≥80% |
| KR4 | 单笔贡献毛利（实付−分成−支付手续费−直接获客） | 均值趋近 ≥20%，或有清晰爬坡路径 |
| KR5 | 「不确定→转专家」点击率（有展示机会时） | ≥20% |

---

## 5. Market Segment(s)

**首要用户（需求方）**  
- 中小企业财务、代理记账同事：日常增值税/发票政策口径问题，要快、要依据、重活才找人。

**供给侧**  
- 持证税务师/顾问：愿按单接、按分成拿钱，不要求坐班。

**约束**  
- 首发仅 **增值税高频**（含常见发票政策问答口径），不做全税种。  
- 答复为**参考意见**，非正式税务鉴证；高风险必须转专家或拒答。

| 对象 | 得到什么 | 避开什么 | 相对智税宝 |
|------|----------|----------|------------|

| 平台 | 验证付费与供给；知识可回流 | 先堆千万级全库 | 滩头窄、可挂载后续税务产品 |

## 7. Solution

### 7.1 用户流程

```text
注册/登录（可先手机号）
    → 提问（可补：纳税人类型/地区）
    → AI 答案卡片：结论 | 依据条款（强制引用）| 适用边界 | 免责
    → 分支：
         A. 满意结束 / 追问
         B. 显示「不确定」或用户点「转专家」
            → 报价（如 ¥99/199）→ 支付
            → 工单：打包对话 + AI 草稿 → 专家领取
            → 专家书面答复 → 用户评价 → 分账
```

### 7.2 Key Features（MVP 必做）

| ID | 功能 | 验收要点 |
|----|------|----------|
| F1 | **强制引用问答** | 无检索命中不得输出确定性结论；每条结论绑定条款 chunk；前端可点开原文/文号 |
| F2 | **窄域条款库** | 增值税高频：法规→条款→适用条件标签；现行有效默认；人工可上下架 |
| F3 | **答案卡片** | 结论 / 依据 / 边界 / 免责；「不确定」显式态 + 补槽引导 |
| F4 | **转专家按单** | 报价→支付→工单状态（待接/处理中/已完成/退款）；上下文一键移交 |
| F5 | **专家工作台（简）** | 领单、回写书面答复、标记可回流；查看 SLA 倒计时 |
| F6 | **分账记账** | 每单：实付、手续费、专家分成、平台留存；可导出 |
| F7 | **黄金集与门禁** | ≥50 题；发版前跑引用正确率；不达标不扩流量 |

### 7.3 明确不做（MVP Out）

- 全税种百科、场景剧本库主形态、企业私有库  
- 发票解析 / 购销链 / 税务体检全量 / 申报算税  
- 自训大模型、私有化部署、多租户复杂 SaaS 计费  
- 企业风险咨询完整产品（仅预留：企业主体字段、工单类型枚举可扩展）

### 7.4 Technology（建议）

| 层 | MVP 选型 |
|----|----------|
| 模型 | 公有云 API + Prompt 版本管理 |
| 知识 | **权威原文真源** + 按法条切块；**LLM 蒸馏仅辅助**打标/适用条件/题库草稿（禁止无原文入库）+ 向量/关键词混合检索 + 强制引用；详见 `prd/backlog-mvp-tasks.md` M1-02 |
| 应用 | Web 对话 + 简易管理/专家台；会话与工单用常规业务库 |
| 支付 | 微信支付/企支付宝其一即可；分账可先半自动（表记账 + 月结专家） |
| 质量 | 黄金集离线评测；人工抽检台（表格也可起步） |

### 7.5 Assumptions（边做边验，写入验收）

| ID | 假设 | MVP 内如何验 |
|----|------|----------------|
| V2 | 用户愿为专家书面单付费 | 真支付 ≥8 |
| G3 | 专家愿按分成接单 | ≥5 人试接 |
| B1 | 分成后平台有毛利空间 | 分账表 |
| F1 | 引用质量可达线 | 黄金集 ≥70% |
| B3 | 窄库冷启动可接受 | 建库 ≤15 人天量级追踪 |
| U2 | 「不确定」促转单 | 点击率 |

## 8. Release

### 阶段与周期（相对时间）

| 阶段 | 周期 | 交付 |
|------|------|------|
| **M0 准备** | 约 1 周 | 锁定增值税题单与语料源；招募 ≥5 专家意向；法务免责模板 |
| **M1 知识+问答** | 约 2–3 周 | 切块入库、强制引用对话、答案卡片、黄金集门禁 |
| **M2 按单闭环** | 约 2 周 | 支付、工单、专家台、分账表；内测真单 |
| **M3 Concierge 放量** | 约 1–2 周 | 小流量获客；盯 KR；周复盘停损 |

**总窗**：约 **6–8 周** Concierge MVP（远小于完整对标智税宝的 110–180 万「咨询问答产品化」；本 MVP 按 **人少 + 半自动运营** 控成本）。

### 人员建议（最小）

| 角色 | 投入 |
|------|------|
| 全栈或后前端各 1 | 主研发 |
| AI/RAG 0.5–1 | 检索与评测 |
| 财税专家 0.5 | 切块质检与黄金集 |
| 产品 0.5 | 范围与 Concierge 运营 |

### 停损

- 黄金集引用正确率持续 &lt;50% → 收窄题域或改为「检索展示+专家为主」  
- 2 周无真付费且专家接单意愿不足 → 暂停获客，复盘定价/分成或改供给模式  

### 下一版本（Post-MVP）

- 扩税种 / 时效流水线自动化 / 知识回流审核  
- 挂载企业风险咨询入口  
- 多租户与自助订阅包

## 附录 B — 与成本评估的关系

完整「咨询问答产品化」MVP 预算中位约 145 万（见研发成本 Canvas）。**本 Concierge MVP** 通过缩税种、半自动分账、专家台极简、少做平台化，目标压在 **显著低于该中位** 的人月内完成验证；验证通过后再按标准版技术层加码。
