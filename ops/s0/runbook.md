# Sprint 0 Runbook（双周）

**Sprint Goal**：假门 + 真单/影子单 + 10 题小样，验证愿付 ∩ 愿接 ∩ 库可做。  
**站会每日 10 分钟只盯**：名单触达、估价/意向金、专家确认数、10 题进度、是否偷做大功能。

日期请按实际开跑日改写（下表以 D1–D10 计）。

**本轮开跑**：D1 = **2026-07-28** → D10 = **2026-08-08**（详见 `ops/s0/D1-2026-07-28.md`）

## 每日站会三问

1. 昨日：触达 / 点击·意向金 / 专家确认 / 题进度？  
2. 今日：堵点是约人、协议，还是题单？  
3. 有没有人在做 S1 大功能？（有则立刻停）

---

## Concierge SOP（半人工）

```text
用户从 Landing 点「估价」或私域说「想问专家」
  → 运营建单（tracking 分账表）
  → 收款（转账/支付链接；备注订单号）
  → 派给已确认试接专家（企微）
  → 附：问题 + 已知材料 +（可选）产品 AI 草稿与引用
  → 专家 24h 内书面回复
  → 交付用户；记账：实付 / 手续费 / 专家 70% / 平台 30%
  → 请用户一句话评价
```

产品化路径可继续用本地 `apps/` 专家台（`expert-demo`），但 **S0 验收看业务闭环，不卡 UI**。
