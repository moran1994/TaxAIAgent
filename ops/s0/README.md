## S0 出口（必须四闸门）

| 闸门 | Go |
|------|-----|
| 付费 | 估价点击 ≥15% **或** 意向金 ≥5 **或** 真付 ≥3 |
| 供给 | ≥5 专家确认试接；SLA 意向可达 |
| 价带 | 用户替代花费中位 ∩ 专家到手底线 非空 |
| 库 | `spike-10` 可跑通引用路径，人天可接受外推 |
