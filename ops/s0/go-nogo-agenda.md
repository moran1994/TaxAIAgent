# S0 Go / No-Go 会议程（D10）

**时长**：45–60 分钟  
**必须到场**：业务负责人、PM、内容、运营；（Eng 可选）  
**会前**：填完 `tracking.md` + `spike-10.md` 结论  

---

## 1. 闸门宣读（15 min）

| 闸门 | 实际数 | 门槛 | 判定 |
|------|--------|------|------|
| 付费 | 点击率 __%；意向金 __；真付 __ | ≥15% 或意向≥5 或真付≥3 | Go / No |
| 供给 | 试接确认 __ | ≥5 | Go / No |
| 价带 | 重叠区间 ____ | 非空 | Go / No |
| 库 | 10 题命中 __/10；人时 __ | 可外推 | Go / No |

## 2. 红队复查（10 min）

- 是否其实只是申报附属场景？（Kill #2）  
- 「不确定」有没有劝退？（若有小样本）  

## 3. 决议（必须书面一条）

选一：

1. **全 Go** → 启动 Sprint 1（答案卡 + 强制引用产品化）  
2. **付费/供给 Go，库 No** → 保留按单，知识库降级 FAQ/轻检索  
3. **付费或供给 No** → 停按单或改专家市场优先 / 暂停扩面  
4. **仅价带紧张** → 调档位/分成后再开 1 周验证，不进入 S1 大开发
