# M0-02 免责声明与拒答边界

**单一来源**：本文件为产品文案与 Prompt 注入的权威稿（改文只改此处）。  
**状态**：草案 · 待法务/产品负责人确认后方可上线  
**日期**：2026-07-24

---

## 1. 答案页固定免责（短版 · UI 页脚）

> 本回答由 AI 基于公开法规检索生成，仅供一般性学习与工作参考，**不构成税务鉴证、法律意见或申报依据**。政策可能调整，请以主管税务机关口径及正式文件为准。重要决策请咨询持证税务专业人士或使用「转专家」服务。

**Prompt 注入键名**：`DISCLAIMER_SHORT`

---

## 2. 答案页免责（完整版 · 可展开）

> 1. 系统尝试引用公开法规条款；若未检索到足够依据，将明示「不确定」或建议转专家，而非编造结论。  
> 2. 引用文本可能存在切块截断，请点击原文核对全文、生效日期与适用条件。  
> 3. 您的行业、地区、纳税人资格、交易安排等具体事实未经验证；相同问题不同主体结论可能不同。  
> 4. 平台不对依据本回答做出的申报、筹划、合同安排承担法律责任。  
> 5. 付费专家书面答复仍为咨询意见，除非另行签署鉴证/代理协议。

**Prompt 注入键名**：`DISCLAIMER_FULL`

---

## 3. 「不确定」态标准话术

> 依据当前知识库，我无法给出有足够法规支撑的确定结论（原因：{reason}）。你可以补充：纳税人类型 / 所属地区 / 业务事实；或选择 **转专家** 获取书面答复。

`reason` 枚举：`无检索命中` | `条款冲突待人工` | `事实不足` | `高风险主题`

## 4. 拒答 / 强制转专家主题表（≥10）

| ID | 主题 | 动作 | 用户可见说明（摘要） |
|----|------|------|----------------------|
| R01 | 偷逃税、虚开发票、隐瞒收入等违法指引 | **拒答** | 无法提供可能违法的操作建议 |
| R02 | 伪造、变造发票或账簿 | **拒答** | 同上 |
| R03 | 明确要求「帮我设计避税方案且规避稽查」 | **拒答** 或转合规咨询专家 | 不提供规避监管方案 |
| R04 | 需对具体企业做纳税鉴证/审计结论 | **强制转专家** | 超出 AI 参考范围 |
| R05 | 走逃失联企业已抵扣进项善后（个案） | **强制转专家** | 需结合案情与当地口径 |
| R06 | 重大重组、关联交易定价税务安排 | **强制转专家** | 高风险个案 |
| R07 | 出口骗税风险、函调应对策略细节 | **强制转专家** | |
| R08 | 与税务机关争议的复议/诉讼策略 | **强制转专家** | 偏法律程序 |
| R09 | 地方财政返还、招商税收协议解读并指导套利 | **拒答/转专家** | 合规边界不清则拒答 |
| R10 | 要求预测稽查概率或「怎么说能过关」 | **拒答** | |
| R11 | 个人代开虚增成本、虚构业务 | **拒答** | |
| R12 | 知识库无覆盖税种的深度筹划（企税/个税跨境等） | **不确定 + 转专家** | MVP 窄域外 |

**配置键名**：`REFUSAL_RULES`（JSON 可由后端加载本表）
